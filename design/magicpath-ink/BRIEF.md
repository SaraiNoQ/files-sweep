# FileSweep · 墨色三境

MagicPath project: 465512338078961664. Three exploratory interactive desktop concepts, not approved native visual specifications. Demo metadata only. Production Swift and the current root DESIGN.md remain authoritative until selection.

## Direction contract

THESIS: Chinese wuxia ink, flowing silk and mountain mist becomes the spatial language of a read-only disk explorer. File names, measurable size and protection states remain plain and actionable.
OWN-WORLD: 赤墨·断流 uses paper #eeece5, cinnabar #a3322f and ink #222a2c; 青玉·回澜 uses jade paper #e9ede0, deep green #183d37 and gold #b79a51; 霜蓝·云阙 uses mist #edf0f0, slate #203641 and blue #365f78. Native system UI text and Song-style Chinese display type distinguish labels from editorial artwork.
STORY: choose a demonstration root, browse the spatial map, select a folder, inspect metadata, enter and return. Search and the development-artifact filter use the same dataset. Reading failures and skipped volumes stay visible; logical size never implies recoverable space.
FIRST VIEWPORT: A uses a dramatic red/black diagonal brush landscape, a rectangular treemap and lower directory/inspector. B centers a jade radial space navigator between the legend and object details, with a full-width lower list. C uses a frost-blue mountain banner, expanding vertical folios, and the lower directory/inspector.
FORM: three user-requested alternatives; code-led interactive canvas concepts. Signature interactions: blade-glint selection, ring-to-directory navigation, and unfolding folio selection. Reduced-motion support; no destructive controls, AI sends, or real filesystem access.
FINISH: inspect rendered canvas components, run independent finish review, record concept tokens without replacing the approved app design; every shipping raster carries provenance.
