# AI 辅助判断

默认关闭，由用户自填兼容 Chat Completions 的完整接口地址、模型 ID 和 API 密钥。网络层使用系统 URLSession，没有 SDK 或新增包。详情中的“AI 辅助判断”固定展示“这是什么、删除前还缺什么信息、建议怎么检查”三部分，不改变本地识别、保护规则或文件，不提供删除许可。

## 使用

先在 FileSweep → 设置…（⌘,）中填写接口地址、模型与密钥，启用并保存。文件详情中的 AI 弹窗只负责等待和展示结果，不包含配置表单、提示词或二次确认。

选中项目 → 点击 AI 辅助判断 → 直接发送本次脱敏信息并等待 → 展示结果。

2026-10-28 用户明确要求取消提示词展示和二次确认；点击“AI 辅助判断”就是本次请求的发送动作。设置中说明发送范围、费用和服务端保留边界。尚未启用时只引导打开设置，不发送。保存设置不会发起请求；返回原弹窗需主动点“开始判断”。取消、失败或修改设置后不会自动重发，需主动再次开始或重试。

地址必须是实际 POST 接口，例如 `https://api.openai.com/v1/chat/completions`；不会自动拼接路径。模型 ID 按服务实际提供的值填写。无内置模型、密钥或默认云端接收方。本机模型可显式配置 `http://localhost:端口/v1/chat/completions`、`127.0.0.1` 或 `[::1]`，允许不填密钥。其余服务要求 HTTPS 和密钥。

密钥按完整接口地址存入本机 macOS 钥匙串，不放 UserDefaults、日志或文件。编辑地址时清空输入框中的旧密钥，避免将它误传给另一服务；旧地址密钥仍留在钥匙串，需要时先回到该地址再移除。“移除当前密钥并关闭 AI”只删除已保存的当前地址密钥。关闭设置窗口不保存草稿；保存设置不会发起网络请求。

## 请求协议

实现参考 [OpenAI Chat Completions API](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。固定使用非流式、`response_format: {"type":"json_object"}`、`max_completion_tokens: 1600`、`store: false`；服务需支持这些字段与 `choices[].message.content` 响应格式。兼容服务不保证全部支持，HTTP 失败可修改配置后手动重试，不自动换协议、重试或探测服务。

每次点击直接从该弹窗捕获的脱敏上下文构造请求，不在界面展示内部 JSON 或提示词。请求正文在本次发送期间不可变。密钥仅进入该地址的 Authorization 头，不进入正文。拒绝 URL 用户信息、查询参数与片段，阻止全部 HTTP 重定向。请求不携带 cookies、持久缓存或系统存储的 HTTP 凭据。

## 结果格式

协议仍使用 explanation / missingEvidence / manualChecks 三个固定字段，界面分别展示“这是什么”“删除前还缺什么信息”“建议怎么检查”。提示词要求用途说明为 2–3 个短句，总计不超过 180 字；后两部分各 1–3 条，每条不超过 60 字。用日常中文，不复述内部枚举、规则 ID 或子项别名；只说有依据的用途、未知事项和具体人工检查。没有证据时直接说明不能判断，不为凑格式编造事实。结构由客户端校验与原生布局固定，实际措辞仍受模型影响。

## 数据边界

`ExplanationContext` schema v2 从白名单构造：类型、粗粒度体积、固定名称与后缀类别线索、本地规则 ID/生态/类型/保护等级、历史/过期/完整性状态，以及固定的未知事项。子项最多 20 个，使用临时 item-N 别名；不发送精确子树与任意扩展名。规则 ID 也须属于本地固定白名单。

原始路径、个人文件名、原始时间、文件内容、环境变量、Git remote、xattr、凭据及原始目录树均不进入上下文；本地证据和保护原因的任意文本也不直接序列化。名称与后缀仅为线索，不构成用途事实或可删除性依据。结构与技术栈仍可能敏感，脱敏不等于绝对匿名。

模型看不到个人内容，也不知道使用状态、Git 跟踪、源码是否存在、能否重新下载或重建。未知、受保护、历史、过期和不完整状态不会被 AI 降级。每份结果上方保留独立的本地判断，结果末尾标注可能错误及不代表删除许可。

## 失败与生命周期

单窗口最多一个请求。请求上限 32 KiB；响应按接收字节限制到 128 KiB，时限 60 秒。仅接受一个正常完成的结构化结果；拒绝拒答、截断、字段异常、空内容或超长内容。服务正文与凭据不会拼入错误提示。输出使用纯文本，不执行命令、不渲染 HTML、不访问模型提出的路径、不追加收集数据。

解释固定属于打开弹窗时的扫描快照：保存本地代次、索引、目标位置与文件身份，绝不把捕获索引用到新快照。后台更新时，按位置与 device/inode 验证仍为同一项目，允许目录索引重排；保留固定请求上下文与进行中的解释，并保守标记“受保护 · 目录已变化，仅供打开时的快照参考”。界面显示所依据快照的时间，模型上下文固定声明只解释快照、不代表当前文件系统状态。时间、位置和文件身份仅在本地使用，不上传。

取消、关闭弹窗、真正切换文件、目标移除或替换、手动重扫/打开记录、根目录变化及关闭窗口均取消任务；任务身份与有效状态双重检查丢弃迟到结果。回复只写入原会话，不写入或覆盖更新后的扫描快照。重试必须由用户再次点击，不自动重试。扫描、搜索、选择项目和自动更新均不会自行发送请求；关闭 AI 不影响本地功能。多个窗口分别受本窗口的点击请求约束。

对话和结果仅保留在当前弹窗，不默认持久化。`store:false` 不等同服务端零保留，保留政策取决于用户选择的服务；请求可能产生费用。

## 验证

35 项核心检查通过，其中 AI 检查覆盖脱敏、状态保护、地址限制、请求正文与捕获上下文一致性、结构化响应、HTTP 失败、响应上限与请求取消；网络检查由 URLProtocol 模拟，不连接真实服务。`scripts/check-ai-session.sh` 覆盖单次启动与并发抑制、取消或失败后不自动重发、显式重试、取消与迟到结果、后台变化不中断快照参考、同文件索引重排、目标身份替换、根目录变化、手动重扫与关闭窗口；`scripts/check-ai-settings.sh` 在隔离设置中检查默认关闭、配置验证与密钥格式，不读取或写入真实密钥。

真实服务兼容性与生成质量、签名应用的钥匙串正常读写/权限提示、真实窗口视觉、VoiceOver 和 macOS 13 实机仍需验证。没有读取环境或用户密钥进行付费请求，也没有上传个人目录数据。
