# 本地扫描记录 v0.3

用户主动保存当前扫描为 `.filesweep` 文件，通过菜单或 ⇧⌘O 恢复。没有后台自动保存，也不自动扫描记录中的原始路径。

## 数据与隐私

使用 macOS 自带 SQLite，格式版本 1。记录根路径、扫描时间、条目名称/父子关系/类型/大小/修改时间，以及读取问题与取消状态。不包含被扫描文件的正文，也不保存模型对话或凭据。

这是未加密的本地元数据报告，文件名与路径本身可能敏感。保存对话框说明包含内容，文件初始权限为 0600。用户决定保存位置和是否分享。

## 保存与恢复

- 临时文件建在用户选定的目标目录，SQLite 事务提交后原子重命名；失败不以半成品覆盖原记录。
- 使用单个数据库文件，不依赖外部 WAL 文件。不接受符号链接、目录作为保存目标或导入源。
- 加载只读打开数据库；拒绝未知版本、错误表类型、过长字段、异常数字、非连续标识、循环/越界父子关系、路径穿越、错误聚合或溢出。不会执行记录中的字符串。
- 当前最多 200 万条目、512 MiB 文件；超过限制明确拒绝。UInt64 大小以十进制文本保存，避免 SQLite 有符号整数截断。
- 子节点索引从验证后的父子关系重建，不依赖文件内重复存储的索引。
- 恢复后重新使用当前开发规则分析；历史候选项一律受保护，提示当前状态未核验。只有用户主动重扫才能得到新结果。
- 不校验历史路径当前是否存在、不主动取得访问权限；Finder 定位时检查可访问性并报告失败。

## 验证

4 组存储回归检查覆盖精确往返、只读加载、0600 权限、历史保护、损坏数据库、目录循环、越界名称、过长字段、未知版本/类型、异常数字、视图替换、失败保存与符号链接拒绝、部分扫描状态及大于 Int64.max 的逻辑大小。

百万条目合成记录：约 46.6 MiB，保存 1.25 秒、读取 1.85 秒，内容计数与根目录统计往返一致。单次本机测量，缓存状态未控制；原始结果在 `benchmark-archive.json`，不代表所有磁盘或文件名分布。

记录文件不存储实时监听句柄或跨启动事件游标。v0.4 在用户手动重扫后可以启用当前窗口的 FSEvents 增量更新；直接打开记录仍保持历史状态。SQLite 查询索引、扫描差异比较与跨启动自动恢复尚未实现。
