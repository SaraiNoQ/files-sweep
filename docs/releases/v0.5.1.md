# FileSweep v0.5.1

2026-10-29 · macOS 13+ · Apple Silicon（arm64）· 构建号 6。

本版改进安装与升级方式，应用功能与 v0.5.0 相同。

## 直接升级，无需卸载

双击 `FileSweep-0.5.1-macos-arm64.pkg`，按系统安装步骤继续。首次安装放到 `/Applications/FileSweep.app`；如果此前按说明安装了 v0.4.0/v0.5.0，会由系统安装器覆盖升级同一应用，不需要先卸载，也不需要手动拖动替换。旧版仍在运行时，安装器要求关闭后再继续。

安装包仅包含应用文件，不包含用户 Library、偏好设置、钥匙串或扫描记录，也没有迁移/删除/自定义提权脚本。应用标识仍为 `dev.filesweep.mac`，既有设置和密钥保留。手动放在其他位置的副本不会自动移动或删除。

PKG 使用固定包标识 `dev.filesweep.mac.pkg`，启用版本检查、严格应用标识与整包升级，禁用重定位，避免把构建目录、挂载镜像或其他手动副本误作升级目标。不得用旧安装包覆盖较新的应用。版本检查作用于应用 bundle，之前以拖拽方式安装、没有 PKG 收据的标准路径副本同样受这些规则管理。

这是“运行新安装包时自动覆盖升级”，不是后台检查、下载或静默安装更新。扫描的“自动更新”仍默认关闭，与软件版本升级无关。

## 安装包与校验

- `dist/FileSweep-0.5.1-macos-arm64.pkg`：推荐安装/升级入口。
- `dist/FileSweep-0.5.1-macos-arm64.dmg`：内含相同 PKG 和安装说明。
- `dist/FileSweep-0.5.1-arm64.zip`：便携应用，解压本身不执行安装或升级。
- [v0.5.1-SHA256SUMS.txt](v0.5.1-SHA256SUMS.txt)：本次产物校验值。

安装器目前未签名；应用采用 ad-hoc 临时签名，未经 Apple 公证。macOS 可能阻止首次打开，系统安装器也可能请求管理员授权。请核对下载来源，再参考 [Apple 官方说明](https://support.apple.com/zh-cn/guide/mac-help/mh40616/mac)。

## 验证范围

构建后自动展开 PKG，检查退出运行中应用的规则、arm64/macOS 13 限制、固定安装位置、bundle/包标识、版本检查、整包升级、禁止重定位和自定义脚本缺席；确认载荷只在 Applications/FileSweep.app 下，所有文件逐字节匹配当前签名应用，应用严格签名校验通过。DMG 只读挂载后核对 PKG 一致，ZIP 完整性和 SHA-256 校验通过。

没有执行真实安装或卸载，没有修改这台电脑的 /Applications、偏好设置或钥匙串。真实旧版运行中的退出提示、升级后的钥匙串授权和 macOS 13 实机仍需人工验收。此记录不表示已创建 GitHub Release。

实现依据：系统 pkgbuild 手册的 BundleOverwriteAction/BundleIsVersionChecked/BundleIsRelocatable/BundleHasStrictIdentifier，以及 [Apple Installer Distribution XML](https://developer.apple.com/library/archive/documentation/DeveloperTools/Reference/DistributionDefinitionRef/Chapters/Distribution_XML_Ref.html) 的 must-close、domains 与 allowed-os-versions。
