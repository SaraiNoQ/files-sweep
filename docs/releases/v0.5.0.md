# FileSweep v0.5.0

2026-10-29 · macOS 13+ · Apple Silicon（arm64）· 构建号 5。

## 安装

本地构建输出：

- `dist/FileSweep-0.5.0-macos-arm64.dmg`：打开后将 FileSweep.app 拖到 Applications。
- `dist/FileSweep-0.5.0-arm64.zip`：解压后将应用放入“应用程序”。
- `dist/SHA256SUMS.txt`：安装包校验值，副本见 [v0.5.0-SHA256SUMS.txt](v0.5.0-SHA256SUMS.txt)。

更新前先退出旧版应用。当前使用 ad-hoc 临时签名，尚未经过 Developer ID 签名或 Apple 公证；首次打开可能被 macOS 阻止，请核对来源后参考 [Apple 官方说明](https://support.apple.com/zh-cn/guide/mac-help/mh40616/mac)。

## 新增与调整

- 接入可配置的 Chat Completions AI 辅助判断。连接信息在原生“设置…”（⌘,）中填写，密钥仅存本机钥匙串；AI 默认关闭。
- 点击 AI 辅助判断后直接发送脱敏信息并等待，固定展示“这是什么、删除前还缺什么信息、建议怎么检查”，不显示内部提示词或二次确认。
- 解释绑定打开时的扫描快照；后台变化不再让同一目标的解释反复失效。目标切换、移除、替换或窗口关闭仍取消旧请求；失败、取消后不自动重发。
- 自动更新默认关闭，由工具栏主动开启；继续限定在当前窗口选择的根目录内。
- 更新纸色、墨青和朱砂应用图标，统一标题、正文、辅助信息层级，固定详情底部操作。
- 详情、AI 长回复及读取问题列表复用原生透明滚动容器；改善长名称换行、窄窗口与错误恢复排版。设置支持回车保存。

扫描与规则分析只读取元数据，不读取文件内容、不删除文件、不提权。可选 AI 请求只包含白名单脱敏线索，不发送原始路径、个人文件名、文件内容或原始目录树；结构和技术栈线索仍可能敏感，服务可能收费并保留请求。AI 不改变本地保护规则，也不代表删除许可。逻辑大小和分配空间不等于实际可回收空间。

## 验证与边界

35 项核心检查，以及原生滚动条、目录、环图输入、AI 会话与设置回归通过。安装包经 DMG 镜像校验、只读挂载核对、ZIP 完整性、版本与资源一致性、应用签名和 SHA-256 校验。

构建先独立签名再原子替换，保留旧包以免影响仍在运行的进程。尚未完成 macOS 13 实机、VoiceOver、系统文字缩放、真实模型兼容性和系统钥匙串提示验收。
