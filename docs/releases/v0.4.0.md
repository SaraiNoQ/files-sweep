# FileSweep v0.4.0

适用于 macOS 13 及以上版本，仅支持 Apple Silicon（arm64）。

## 安装

下载 `FileSweep-0.4.0-macos-arm64.dmg`，打开后将 `FileSweep.app` 拖入 `Applications`。更新前请先退出旧版应用。也提供 ZIP 压缩包和 `SHA256SUMS.txt` 校验文件。

**签名状态：此版本使用 ad-hoc 临时签名，尚未经过 Developer ID 签名或 Apple 公证。** macOS 可能阻止首次打开；请先核对下载来源，再参考 [Apple 官方说明](https://support.apple.com/zh-cn/guide/mac-help/mh40616/mac)。

## 本版功能

- 只读扫描所选目录的文件元数据，提供文件名搜索、目录树、多层环图、Treemap 和 Finder 定位。
- 识别 Python、Node、Rust、Go、Java 的开发产物，展示识别依据和保护状态。
- 支持保存与打开本地扫描记录，以及当前根目录的增量更新。
- 保留纸色、朱砂和墨色配色，简化玻璃层级；合并环图绘制，减少重复模糊、投影和悬停重绘。

不读取文件正文，不删除文件，不提权，不上传扫描数据。逻辑大小和分配空间不等于实际可回收空间。

## 验证与边界

32 项核心检查，以及环图输入、搜索和目录树回归通过。DMG 经镜像校验、只读挂载核对及应用签名完整性验证。

尚未完成 macOS 13 实机、VoiceOver 与真实屏幕帧率验证；离屏性能测试不等同于实际 FPS。
